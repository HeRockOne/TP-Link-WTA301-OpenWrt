# WTA301 · OpenWrt 25.12.6 —— 发布包

本包给 **TP-Link WTA301**（IPQ5018 + QCN6122 + RTL8367S，256 MiB RAM / 128 MiB NAND）。

里面两样东西，**用途不同、风险不同，不要混**：

| 目录 | 内容 | 风险 |
|---|---|---|
| `firmware/` | 可直接刷的 OpenWrt 固件（三种包） | 刷错版本会写错偏移，但可用 u-boot 网页恢复 |
| `uboot-kit/` | u-boot 源码 overlay + 构建脚本 + 槽镜像 | **刷错串口直接死**，链错基址就救不回来 |

源码、分析文档、全部实测证据在仓库里；本包只放成品和 u-boot kit。

---

## 一、三个固件包，选哪个

| 文件 | 大小 | 什么时候用 |
|---|---|---|
| `wta301-op-25.12.6-*.bin` | 17,170,432 B | **第一次刷**（原厂 → OpenWrt，或从老版本过来）。走 u-boot 网页 |
| `wta301-op-25.12.6-*-sysupgrade.bin` | ~13.4 MB | **已经跑本固件**，要升级。LuCI 里直接刷 |
| `rescue/wta301-op-25.12.6-*-ttl.bin` | 20,447,232 B | 串口救砖。**只有串口能刷，网页刷不了** |

前两个是**紧凑布局**（`0x1060000`），第三个是**稀疏布局**（`0x1380000`，含头尾填充）。
尺寸不一样就是这个原因，不是打包出错。

## 二、第一次刷（u-boot 网页）

1. **断电**。按住 `reset` 不放，插电。等约 **40 秒**，指示灯变**红灯常亮**。
2. 网线接任一 LAN 口。电脑网卡设静态 `192.168.1.2 / 255.255.255.0`。
3. 浏览器开 `http://192.168.1.1`。
4. 选 `wta301-op-25.12.6-*.bin` 上传。页面会**先校验再写**，校验不过不会写。
5. 刷完**手动执行 `bootipq`**（页面提示时），不要以为它会自己重启。

> 错过 3 秒窗口进不去？断电重来。u-boot failsafe 有 180 秒空闲超时，
> 动作慢一点没关系，只要进了红灯就一直等着你。

## 三、之后的升级（不用进 u-boot）

LuCI →「系统」→「备份/刷写固件」→ 选 `*-sysupgrade.bin` → 取消勾选「保留配置」以外的选项
（默认就好）→ 刷写。

**配置和已装软件包会自动保留** —— 本板的 overlay 在独立的 UBI 卷（`wta301data`）上，
升级只写 kernel + rootfs 两个分区，碰不到 overlay。

命令行等价：

```sh
sysupgrade -T /tmp/wta301-op-25.12.6-*-sysupgrade.bin   # 先干跑校验，不写
sysupgrade    /tmp/wta301-op-25.12.6-*-sysupgrade.bin   # 真刷
```

## 四、回原厂

原厂固件一直躺在 B 槽（`mtd10` + `mtd11`）里，没人动过。
把原厂 A 槽镜像写回 `mtd5` + `mtd6` 即可，`boot_flag` 不用改。

**B 槽（`mtd9/10/11`）任何时候都不要擦。**

## 六、校验

每个子目录有 `MD5SUMS.txt`。刷之前对一遍：

```sh
md5sum -c MD5SUMS.txt
```

`firmware/FINGERPRINT.json` 里是分区偏移、长度、crc32 的完整指纹，
出问题时把它贴出来就能定位是哪个分区不对。

## 七、u-boot kit 使用者请注意

`uboot-kit/` 里是**u-boot 新增代码全量 overlay**（23 个文件）+ 构建脚本 + 槽镜像。
**动手前必须读 `uboot-kit/README.md`**，尤其 §4「四个必须知道的坑」：

- 二级 u-boot 链接基址必须是 **`0x49900000`**，不是 `0x4a920000`（后者链上去串口直接死）
- 槽内容必须是 **LZMA-Alone** 流，一级没有裸镜像回退
- 未压缩 ≤ `0xa0000`（640 KB），槽 ≤ `0x40000`（256 KB）
- **不能 `make distclean`** —— 会删掉手写的 DTS

写入顺序永远是「**先写槽、后改头**」：中途断电时头里的 md5 还是旧的，
一级判定该槽损坏 → 自动降另一个槽 → 砖不了。

`uboot-kit/` 里**不含** p18~p21 的历史快照 —— 那些目录同名文件内容不同，
放进来只会让人拿错。要追溯历史请去仓库。
